Gestion du portfolio Modifiez votre contenu, puis téléchargez data.js.
Comment publier : 1. modifiez les champs ci-dessous. 2. cliquez sur « Télécharger data.js ». 3. sur GitHub, ouvrez votre dépôt, cliquez sur Add file → Upload files et déposez le fichier data.js (il remplace l'ancien). Les images doivent déjà être dans le dossier assets/ du dépôt (même chemin que dans le champ « Image »).
